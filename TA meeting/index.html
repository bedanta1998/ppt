Video & Study Content Guidelines NOC Course Video Standards

TAs must ensure the following guidelines are met for video and study materials every week:

Video Releases & Summaries

  • Video Length: 2.0 to 2.5 hours (120-150 minutes) of recorded video lectures per week.
  • Video Summaries: Create a summary of 3-4 key points for each video to be mentioned alongside on the portal.
  • Tutorial Videos: Include one "tutorial" video showing working out of problems, if applicable.

Study Material & Self-Tests

  • Lecture Notes: Ensure notes or slides are uploaded on the portal whenever available.
  • Additional Resources: Provide links to additional reading resources and references.
  • Self-Testing Questions: Create 2-3 questions for self-testing for every 10 minutes of video (configured below video, non-graded).
Weekly Assignments Specifications Assessment Guidelines

Objective Assignments

  • Volume: 8-10 questions per week.
  • Mandatory Solutions: Release detailed worked out solution or recording video. Just final answers are NOT enough.
  • Question Types:
    • MCQ (Single correct answer)
    • MSQ (Multiple correct select options)
    • Short Answer (Numerical or Alpha-numerical)
    • Comprehension passages

Subjective & Prereq

  • Subjective Upload: Scan/upload PDF to Drive or write on the portal (manual grading).
  • Total Marks: Mention total marks for the assignment. Evaluation is done out of 100.
  • Assignment 0: Released on week 0 based entirely on course prerequisites.
  • Quality Check: Ensure assignments are error-free; errors destroy candidate confidence for the final exam.

Types of Assignment Questions Auto-Graded Formats

NPTEL supports a wide variety of auto-graded question formats configuration on the portal:

  • MCQ / MSQ: Multiple choice / select options.
  • Numerical: Fill-in-the-blanks or objective.
  • Alphanumeric: Text match patterns.
  • Numeric Array: For vectors & matrices.
  • Programming: Compiler-graded scripts.
[MCQ] Which of these are...
[NUM] Calculate value: [ ____ ]
[PROG] Python: def solution()...
Auto-Graded: MCQ & MSQ Details Multiple Choice / Select Options
  • MCQ Choice Density:
    • Provide up to 8 choices to reduce guessing probability (4 choices = 25% guess chance, 6 choices = 17% chance, 8 choices = 12.5% chance).
  • MSQ Option Guidelines:
    • Avoid using filler options like "None of the above" / "All of the above" in MSQs to prevent logical contradictions.
    • Strict Penalties: Selecting any incorrect option forfeits all marks (score = 0). Partial grading applies only if no incorrect choices are checked.
  • Descriptive Courses: Include a higher ratio of MSQs than MCQs to evaluate comprehension.
💡 Validation Tip: TAs must cross-check and independently solve each other's keys before assignments go live!
Auto-Graded: Numerical Questions Fill in the Blanks Rules
  • Numerical Specifications:
    • Answers accept only digits 0-9 and a single decimal point. Letters or units must not be typed by students (specify units in the question text).
    • Range Configuration: Unless the answer is an integer, always configure a range instead of an exact value (e.g., target 1.72 with ±0.01 tolerance -> 1.71 to 1.73).
    • Precision Exception: For 1-step problems, the range does not have to be broadened if you want students to learn the importance of not rounding off excessively.
⚠️ Important: Ensure configured ranges are wide enough to account for all reasonable approximations. Narrow ranges trigger heavy student complaints.
Alphanumeric, Array & Programming Advanced Question Configuration

Alphanumeric

Matches text values. Strictly uses Exact Match (fragile: any extra spaces, characters, or casing difference results in 0 marks). Use single-word answers.

⚠️ In exams, ONLY Exact Match is supported.

Numeric Array

Used to configure vectors, matrices, or array responses (e.g. checking all elements in order).

Programming

Code compilation checks. Supported languages: C, C++, Java, Python, Verilog, Perl, Haskell.

MCQ & MSQ Configuration Multiple Choice / Select Details

Pre-Release Verification Checklist Preventing Key/Config Bugs

TAs must run this mandatory checklist on the portal before making any assignment public:

1. Verification Mode

  • Keep the "Check Answers" option ON.
  • Input correct keys and confirm the system marks them as 100% correct.
  • Try different combinations of incorrect keys to check scores and rules.
  • Cross-Checking: TAs must cross-check each other's keys before release.

2. Release Settings

  • Turn the "Check Answers" option OFF after testing.
  • Enable Multiple Submissions (Mandatory).
  • Verify that no question has its weight set to 0.

Short Answer Specifications Autograded Text & Math

Numerical Questions

  • Accepts only numbers, signs, and decimals. No letters or units.
  • Format: Unless the answer is an integer, always specify a range instead of an exact value.
  • Range Rules: Range must accommodate rounding. For example, if correct is 1.72 with ±0.01 error, use 1.71 to 1.73. Ensure range is sufficient.
  • Precision Training Exception: For 1-step problems, range doesn't have to be broadened if you want students to learn not to round off excessively.

Alphanumeric Questions

  • Accepts any keyboard characters except ~.
  • Matches are strictly Exact Match.
  • Crucial: Extra space, spaces inside, or casing differences results in 0 marks.
  • Best Practice: Use single-word answers to avoid grading mismatch.

Comprehension Questions Linked Problem Sets

Comprehension layouts are used to evaluate complex, multi-layered problems:

Structure: A main passage or problem statement (equations, code, or diagrams) followed by 2-3 linked sub-questions.
  • Descriptive Courses Strategy: Excellent for descriptive courses where questions require learners to read and analyze the content once or twice before answering.
  • Sub-Question Formats: Can be MCQs, MSQs, or numerical/subjective short answers.
Subjective & Essay Assignment Guidelines Manual Grading & Final Exam Prep

Setup & Evaluation Workflow

  • Course Staff Allocation: All grading staff must be added to the portal before the assignment is made public, otherwise submissions will not allocate.
  • Grading Scale: Evaluation must be done out of 100 total marks.
  • Visibility: Scores are visible to students only after being officially entered on the portal.
  • Grading Deadline: Exactly 2 weeks from the assignment due date.
  • Folder Integrity Warning: Never delete or move files from the designated portal folder; this breaks portal file paths.

Essay Questions & Exam Prep

  • Announce Prior: Since the final exam includes essay questions, notify students in advance.
  • Practice Assignments: Include essay questions in 1 or 2 assignments (e.g. the last 2-3 weeks).
  • Sample Answer Notes: Create and publish expected sample answers to guide learners.
Assignment Weightage Settings Grading Config
  • Marks conversion: All weekly assignment scores are converted into percentage values for final certificates weightage calculations.
  • Question-level weights:
    • Each individual question can be assigned a custom weight on the portal.
    • Standard question weights range from 1 to 3 marks depending on complexity.
    • TAs must verify that no question is erroneously set to 0 weight.
💡 Grading Rule: Set weights before making the assignment public. Post-deadline changes to weights force expensive re-grading jobs.
Handling Assignment Errors Troubleshooting portal bugs

Scenario A: Incorrect Key Config

A correct option was marked incorrectly on the portal interface.

Action: Correct the option key in the portal panel and run a re-evaluation job to recalculate grades.

Scenario B: Defective Question

All options listed are incorrect, or the question contains errors.

Action: Cancel the question entirely and deduct its weight from the weekly total.

The Cost of Assignment Errors Quality Impact

Why errors are highly disruptive

  • Time Intensive: Fixing errors requires setting the assignment private, altering keys, executing re-grading jobs, and writing announcements.
  • Financial Overhead: Re-grading costs NPTEL approx. Rs. 25,000 to Rs. 50,000 per week in systems and admin overhead.
  • Destroys Trust: Students cite assignment bugs to challenge exam results, questioning proctored exam accuracy.
